# PPT 转讲义（ppt_to_handout）

> 所属工作流：[自动化备课工作流](../../README.md) · 阶段 ID：`ppt_to_handout` · 状态：**规划中**
>
> 相关阶段：[视频转 PPT](video_to_slides.md)（已实现） · [视频转讲义](video_to_handout.md)（规划中）

## 目标

读取已有 PPT/PPTX 的页面、标题、正文、备注和图片，整理为结构化讲义草稿，减少从现成课件手工整理讲义的工作量。

## 计划输入 / 输出

| 项目 | 内容 |
| --- | --- |
| 输入 | PPT / PPTX 文件 |
| 输出 | 结构化讲义草稿：Markdown；后续可扩展 Word / PDF |
| 建议附带 | 页码、标题层级、正文要点、演讲者备注、页面图片、来源文件信息 |

## 建议实现路径

1. **PPTX 解析**：使用 `python-pptx` 读取幻灯片、形状文本、标题、备注和图片。
2. **版面理解**：区分标题、正文、代码块、表格、图片；对多栏和文本框顺序做合理排序。
3. **讲义结构化**：按幻灯片顺序生成章节和小节；演讲者备注可作为讲解补充或教师提示。
4. **图片导出**：把页面或关键图片保存到项目 `_assets`，在讲义中引用。
5. **人工复核**：提供页面/章节预览和顺序调整；复用 `core/ui/image_dialog.py` 查看大图。
6. **导出**：先实现 Markdown，再考虑 Word/PDF。

## 可复用内容

- `core/project/paths.py`：项目文件与 `_assets` 目录约定。
- `core/ui/image_dialog.py`、`theme.py`。
- 如果后续需要统一讲义模板，可把模板渲染下沉到 `core` 或单独的共享模块。

- [ ] 图片能正确导出并在讲义中引用。
