# 视频转讲义（video_to_handout）

> 所属工作流：[自动化备课工作流](../../README.md) · 阶段 ID：`video_to_handout` · 状态：**规划中**
>
> 相关阶段：[视频转 PPT](video_to_slides.md)（已实现） · [PPT 转讲义](ppt_to_handout.md)（规划中）

## 目标

从网课视频中提取讲解结构、页面时间轴和图文内容，生成可继续编辑的讲义草稿。

与“视频转 PPT”的区别：

- 视频转 PPT 关注“把每一页幻灯片截出来”；
- 视频转讲义关注“讲了什么、按什么顺序讲、哪些内容应该写进讲义”。

## 计划输入 / 输出

| 项目 | 内容 |
| --- | --- |
| 输入 | 网课视频（MP4/MKV/AVI 等） |
| 输出 | 结构化讲义草稿：Markdown；后续可扩展 Word / PDF |
| 建议附带 | 页面截图、时间码、讲解要点、章节结构、来源视频信息 |

## 建议实现路径

1. **视频与音频读取**：复用 `lesson_prep.core.media` 的 `probe_video`、`VideoReader`、`FfmpegSampler`。
2. **页面/场景分割**：可以直接复用 `video_to_slides` 产出的页面时间轴和截图，或在该阶段内实现更轻量的场景切分。
3. **语音转写**：新增 ASR 适配层（本地模型或外部服务），输出带时间码的文本段落。需要明确“是否允许联网/上传音频”。
4. **内容结构化**：按页面时间轴把转写文本、截图和 PPT 标题对齐，生成章节、要点和讲义正文。
5. **人工复核**：复用 `core.ui` 的播放器、预览画布；新增讲义编辑/排序面板。
6. **导出**：先实现 Markdown，再考虑 Word/PDF。

## 可复用内容

- `core/media`：视频探测、逐帧读取、FFmpeg 采样。
- `core/timecode`：时间码解析与格式化。
- `core/project/paths.py`：项目文件与 `_assets` 目录约定。
- `core/ui/player.py`、`preview_canvas.py`、`image_dialog.py`、`theme.py`。
- 可选：读取 `video_to_slides` 导出的 `manifest.json` 和页面截图，作为讲义配图来源。

## 待确定的问题

- 是否需要语音转写？如果不需要，讲义只基于页面截图和视觉文字。
- ASR 使用本地模型还是外部服务？是否允许上传视频/音频？
- 讲义模板和章节粒度的默认规则。
- 输出格式优先级：Markdown、Word、PDF。
- 是否需要与“视频转 PPT”共享同一个项目，还是读取其导出产物。

## 验收标准（建议）

- [ ] 能从一个视频生成带时间码和章节结构的 Markdown 讲义草稿。
- [ ] 页面截图与讲解段落按时间正确对齐。
- [ ] 人工可以修改章节标题、段落顺序和配图。
- [ ] 项目可保存、重新打开和导出。
- [ ] 至少有一条基于合成视频的端到端测试。
