# 视频转 PPT 阶段（video_to_slides）

> 所属工作流：[自动化备课工作流](../../README.md) · 阶段 ID：`video_to_slides` · 状态：已实现
>
> 相关阶段：[视频转讲义](video_to_handout.md)（规划中） · [PPT 转讲义](ppt_to_handout.md)（规划中）

从网课视频中检测 PPT 页面切换，挑选稳定、清晰的页面截图，提供缩略图人工复核，并导出 PNG 图片序列、每页一张的 PPTX 和 JSON 清单。

- 桌面界面：PySide6
- 视频读取/解码：OpenCV + FFmpeg/FFprobe
- 场景候选：PySceneDetect（只作为候选来源，不直接等同于一页 PPT）
- 导出：python-pptx、Pillow/OpenCV
- 所有处理均在本机完成，不上传视频。

> **验证范围说明**：当前目录没有可用的真实网课视频，因此核心流程和界面均使用项目内生成的合成视频（42 秒、1280×720、30 fps，包含片头片尾、硬切、淡入淡出、擦除转场、画笔标注、小范围弹出动画和持续变化的右上角摄像头画面）验证。真实网课视频、真实手写笔迹、真实摄像头画面、长视频性能尚未经过真实素材验证。详见文末“已知限制”。

## 3. 使用流程

1. “导入视频…”支持一次选择多个文件。所有视频会按“视频信息”列表中的顺序拼成一个连续时间轴：播放、时间码、正片区间和分析结果都按总时长计算。之后可用“添加视频…”追加，或用“上移 / 下移 / 移除”调整顺序（改变已有时间轴时会提示候选页面将被清空）。
2. 等待元数据探测完成；预览区可播放、暂停、拖动时间轴、前后 5 秒。双击视频列表中的某一项可定位到该视频起点。
3. 在“正片区间”填入开始/结束时间，或定位到画面后点“取当前”。
4. 点“框选 PPT 区域”，在预览画面中拖拽框选。区域以原始视频归一化坐标保存，预览窗口缩放不会改变区域。区域显示后，可直接拖动边框或四角/边中点控制点调整，无需重新框选。
   - 点“放大预览…”会打开更大的独立预览窗口，可在其中选择“PPT 区域”或某个摄像头后直接框选；窗口内按 F11 可全屏。
   - 最近一次框选的 PPT 区域和摄像头区域（含数量、坐标和处理方式）会保存到本机偏好；重新启动程序或导入新视频时会自动套用，无需从头框选。
5. 当画面存在一个或多个老师摄像头时，在“画面区域”中设置 **摄像头区域数量（0–6）**，会生成对应数量的摄像头条目。逐个点“框选”确定各自区域，并**为每个区域单独选择**：
   - 忽略：仅分析时排除，导出画面保留摄像头；
   - 裁剪：导出时裁掉贴着画面边缘的摄像头条带；
   - 黑色遮罩：导出时用黑色遮住摄像头；
   - 白色遮罩：导出时用白色遮住摄像头。

   多个摄像头区域可以重叠，预览中会显示“摄像头 1 / 2 …”标签；所有已设置区域都会在分析时被排除。区域边框和控制点同样可以直接拖动调整。
6. 可点“修改分析参数…”调整采样率、稳定时间、变化阈值、画质阈值等。
7. 点“开始分析”。第一次分析前会要求保存项目；分析在后台线程执行，有进度条和取消按钮。
8. 在下方“候选页面复核”：
   - 选择缩略图后查看大图和备选帧；
   - 点击备选帧切换选定截图；
   - 删除（无需确认，直接移入回收站）、上移/下移、保留/跳过、批量跳过低置信度；
   - 打开“回收站”选择一个或多个已删除页面恢复；恢复后回到删除前的位置；
   - 点“定位视频”跳到该页在视频中的时间；
   - 点“打开大图”查看可缩放的大图；
   - 双击缩略图也能打开大图；
   - “备注…”写入复核备注。
9. 点“导出幻灯片…”选择输出父目录和内容。多段视频只生成**一份** PNG / PPTX / JSON；每次导出会新建带时间戳的文件夹，不覆盖源视频、项目原始截图或之前的导出。
10. 手动修改会自动保存（项目已有路径时）；关闭窗口时如有未保存修改也会提示。

## 4. 功能与实现

### 多视频连续时间轴

- 导入顺序即拼接顺序；每段视频的时长累加得到总时长，播放器在文件末尾自动切换到下一段。
- 正片区间使用**全局时间**；分析时把全局区间与每段视频求交集，仅扫描参与的交集段。
- 每段视频独立执行粗扫描和稳定帧提取，所有页面时间加上该段在全局时间轴上的起点后统一排序、编号和导出。
- 每页记录 `video_index`；复核面板和导出清单可看出页面来自第几个视频，“定位视频”会自动切换到对应文件。
- 项目 JSON 的 `videos` 数组保存完整顺序和每段元数据，旧版单视频项目仍可直接打开。

### 区域预设

- 每次框选、拖动边框、调整摄像头数量或处理方式后，当前 PPT 区域和摄像头区域列表会立即写入本机 `QSettings`。
- 下次启动程序或导入新视频时自动套用；打开已有项目时仍以项目文件中的区域为准。
- 区域保存的是归一化坐标，因此对不同分辨率的视频同样可用；如新素材布局不同，可直接在预览或放大预览中重新框选。

### 两级检测

1. **粗扫描**（默认 3 fps，可配置 2–4）
   - 优先用 FFmpeg 管道流式采样，单帧处理，不把视频载入内存；
   - 按 PPT 区域裁剪、缩放到分析宽度，并排除所有已设置的摄像头区域；
   - 计算相邻采样帧的变化像素比例、平均绝对差（MAD）和 SSIM；
   - 变化点按时间间隔合并为“过渡候选”，而不是每帧或每个场景都算新页；
   - PySceneDetect `ContentDetector` 复用这些缩放后的 PPT 帧，只提供额外候选时间点。
2. **二次稳定帧采样**（默认 8 fps，可配置 5–10）
   - 在每个候选附近重新读取原始视频帧；
   - 搜索持续稳定 `stable_duration_sec` 的窗口，尽量避免淡入淡出、擦除和加载中的不完整画面；
   - 优先选择非黑屏、非纯色、清晰度较高、后续变化较小的帧；
   - 每个页面保留最多 5 个备选时间点（可配置），再从原视频读取完整分辨率截图。

### 判定信号

- 变化区域占 PPT 有效区域比例（默认 ≥8%）
- SSIM 结构相似度（默认 ≤0.86 为疑似切页）
- 平均绝对差异 MAD（默认 ≥12）
- 页面稳定持续时间（默认 0.75 秒）
- 相邻帧在稳定窗口内的变化比例、SSIM、MAD
- 拉普拉斯方差（模糊检测）、亮度/对比度（黑屏/纯色检测）
- 过渡残余变化、页面持续时间、是否为可疑重复页
- 高度相似的相邻候选自动合并；相似但不确定的保留并标记 `possible_duplicate`/需复核，不静默删除。
- 所有已设置的摄像头区域在差异计算和 PySceneDetect 输入中都被排除；画笔、鼠标和局部动画通常只影响小范围，因此不会单独生成页面。
- 导出时摄像头区域按各自设置顺序处理：裁剪会改变后续区域的坐标映射，遮罩只影响对应区域；无法干净裁剪的内部区域仍会退化为黑色遮罩。

### 人工复核数据

项目 JSON 保存：

- 视频来源列表（顺序、路径、时长、分辨率、帧率、编码、文件大小）；
- 全局正片区间、归一化 PPT 区域；
- 摄像头区域列表（每个区域的归一化坐标、独立处理模式、区域 ID 和数量）；
- 完整分析参数与统计；
- 每个候选页面的全局区间、选定时间、所属视频序号 `video_index`、置信度、异常标记、检测来源、备选帧、备注、保留/跳过状态、人工修改标记；
- 手动变更历史（切换备选帧、删除、恢复、排序、保留/跳过、备注等）；
- 已删除页面的记录（页码、时间、原因）；
- 回收站（保存完整页面数据、删除前位置、删除时间，可重新打开项目后恢复）。

导出时只读取当前项目，不会重新分析，也不会覆盖人工决定。

## 5. 导出结构

导出父目录下会自动创建：

```
<项目名>_slides_YYYYMMDD_HHMMSS/
├─ png/
│  ├─ slide_001.png
│  ├─ slide_002.png
│  └─ ...
├─ raw_candidates/
│  ├─ slide_001_raw.jpg   # 选定候选的原始 PPT 区域截图副本（可选）
│  └─ ...
├─ lecture_slides.pptx
└─ manifest.json
```

- PNG 按当前页面顺序生成，只包含“保留”的页面；
- PPTX 每张图片占一页，页面宽高比按第一张导出图片设置；图片按比例铺满/居中，不拉伸；
- 多段视频共用同一套按全局时间排序的页面，最终只输出一份 `lecture_slides.pptx`；
- JSON 清单包含 `source_videos` 列表、每页的 `video_index` / `source_video`、全局区间、页码、导出序号、候选状态、跳过页、置信度、异常标记、备选帧、手动变更历史、已删除页记录；
- JSON 清单同时记录 `stage`、`stage_name`、每个摄像头区域的坐标、配置模式和实际生效模式；多区域时 `camera_mode` 为 `"multiple"`，并可通过 `camera_regions`、`camera_effective_modes_per_page` 查看明细；
- 被跳过的页面不会进入 PNG/PPTX，但会以 `state: skipped` 出现在 JSON 中；
- 原始项目和导出目录分开，源视频从不修改。

## 8. 已知限制

1. **没有真实网课素材可用**：本次只做了合成视频验证；真实录制中的摄像头噪声、美颜、手写笔迹、复杂 PPT 动画、OBS/录屏编码差异需要进一步实测和调参。
2. 预览不含音频。播放器按帧定时读取，极端情况下播放速度依解码性能略有偏差；工具目标是截图而不是观看完整课程。
3. 逐对象 PPT 动画不能完全解析；系统通过局部变化过滤、稳定时间、重复页合并和人工复核降低误检，但不能保证每个动画变化都正确处理。
4. 长视频（数 GB、小时级）虽采用流式/按需采样且不把原始帧全部载入内存，但尚未用真实多 GB 文件做性能基准；分析仍需数分钟，请用进度和取消按钮。
5. PySceneDetect 在粗扫描的缩放采样帧上运行（约 3 fps），不是原生帧率；它只作为候选补充。
6. 摄像头数量当前支持 0–6 个。每个摄像头“裁剪”只有在摄像头贴着 PPT 区域边缘时才能干净移除；位于画面内部时会自动退回黑色遮罩。单摄像头时兼容使用 `camera_effective_mode`，多摄像头时请查看 `camera_effective_modes` / `camera_effective_modes_per_page`；需要白色遮挡时请选择“白色遮罩”。
7. 多个裁剪区域会按顺序改变导出图片尺寸，最终宽高比可能不同于原始 PPT。对内部孤立摄像头建议使用遮罩而不是裁剪。
8. 原始候选截图以 PPT 区域裁剪后的 JPEG（默认质量 92）保存，以控制长视频磁盘占用；导出 PNG 由这些候选转换而来，不是无损中间帧。源视频不会被修改。
9. 项目文件与 `_assets` 文件夹需一起移动；尚未实现视频文件丢失后的重新关联界面。项目仍可打开并导出已有截图。
10. 导出取消或失败时可能留下一个带时间戳的部分输出文件夹；UI 会提示。
11. 真实视频的默认阈值可能需要按素材调整。可降低变化区域阈值以减少漏检，提高变化/稳定阈值以减少笔迹或动画误检。
12. 多视频按列表顺序直接拼接，不分析音频、不检测语意连续性；每段视频开头都会作为独立候选起点，段与段之间可能出现一个边界候选页，可在复核时删除。
13. 添加视频会追加到末尾，已有页面时间轴保持不变；移除视频或调整顺序会改变时间轴，因此会提示清空现有候选页面并需要重新分析。
14. 区域预设保存在本机偏好中，按归一化坐标套用到所有新导入视频。若不同课程的画面布局或宽高比差异很大，建议导入后先检查区域，必要时在放大预览中重新框选。
